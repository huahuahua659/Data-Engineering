# Data-Engineering

数据方向的学习项目与结论记录。每个子项目都按同一套约定：写清数据口径、特征怎么来的、结果多少、以及哪里站不住脚。

## 项目

| # | 项目 | 内容 |
|---|------|------|
| 01 | [电商订单数据探索](01-ecommerce-data-exploration/) | 字段字典、缺失与异常、表关系、汇总口径核对 |
| 02 | [用户购买倾向预测](02-purchase-propensity-model/) | SQL 特征工程 + 逻辑回归/CatBoost 对比，AUC 0.70 |

## 约定

- 原始数据、特征宽表、预测明细、模型二进制都不入库，只保留可复现的 SQL、代码与结论。
- 数据集为模拟数据，结论用于方法练习，不代表真实业务表现。
- 各子项目 README 里都写明局限，包括做错的地方。
